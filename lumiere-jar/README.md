# LUMIÈRE — 3D-анимация косметической баночки

Фотореалистичный рендер (Blender Cycles, Python-модуль `bpy`): матовое стекло, хромированная крышка,
прозрачная резьбовая горловина, крем с «пиком» и мягкой волной, студийный свет, глубина резкости, motion blur.
Вся сцена строится кодом — никаких внешних моделей и текстур.

## Файлы
| файл | что делает |
|---|---|
| `lumiere_scene.py` | сцена, материалы, свет, камера, расписание анимации, рендер |
| `make_label.py` | текстура этикетки (LUMIÈRE, SKIN RENEWAL CREAM, …) шрифтом Jost, 8192 px |
| `encode.sh` | сборка MP4 из кадров (ffmpeg) |
| `fonts/` | Jost 300/400 (SIL OFL) |

## Запуск
```bash
pip install bpy pillow numpy fonttools     # Python 3.11
python3 lumiere_scene.py info                                  # длительность + проверка столкновений крышки
python3 lumiere_scene.py still 340 test.png --res 1280x720 --samples 6   # один кадр
python3 lumiere_scene.py anim 0 939 frames --res 1280x720 --samples 6    # все кадры (можно по частям; готовые пропускаются)
./encode.sh frames lumiere_jar.mp4
```

## Сценарий (24 к/с, ~39 с, 940 кадров)
1. Закрытая баночка по центру, медленный наезд; оборот на 360° вокруг оси.
2. Крышка плавно поднимается, чуть наклоняется и уходит в сторону (опирается о корпус).
3. Макро крема, мягкая волна на поверхности.
4. Облёт: фронт → 45° → сбоку → сверху → хромированная крышка → матовое стекло → логотип → крем.
5. Крышка возвращается и идеально закрывает баночку; финальный оборот, остановка строго фронтально, лёгкий наезд.

## Качество / разрешение
Параметры `--res` и `--samples` меняются без правок сцены. Видео в репозитории считано на 4-ядерном CPU
(1280×720, 6 сэмплов + шумоподавление OpenImageDenoise, ~12 с/кадр). Для 4K возьмите машину с GPU:
в `build_scene` смените `cy.device = "GPU"` и запустите с `--res 3840x2160 --samples 64`.

Тайминги и камера — в `T` и `camera_keys()` (общий масштаб времени `TS`).
