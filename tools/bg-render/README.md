# Фоновые текстуры сайта (`assets/bg/`)

Десять фоновых картинок за содержимым страниц: **крем** (волны-валики), **мазок крема** (густой мазок с округлым началом и бороздками), **молочный шёлк**, **линии и сетка** (лента из тончайших линий),
**прозрачные плёнки**, **капля и пипетка**, **молекулы** и три рендера упаковки — **баночки с кремом**, два набора **белых флаконов для шампуня** без надписей и без дозаторов (высокие и пониже, крышка с откидным клапаном) (именно они лежат на страницах брендов и товаров).
Крем, молекулы, линии и плёнки нарисованы по референсам заказчика; «клеточная структура кожи», паутинка из нитей с росой, «микрочастицы» (веер нитей с пузырьками), тени листьев, капли с большой линзой,
россыпь капель, «жемчуг и пузырьки», завиток из спиральных валиков и флаконы-«колбочки» с пипеткой, тубы и флаконы с дозаторами убраны с сайта по просьбе заказчика (в истории git остаются). Пузырьков и шариков на фоне нет: там, где они были, лежит мазок крема.
Рисуются здесь, готовые WebP лежат в `assets/bg/` (десктоп `<имя>.webp` и телефон `<имя>-m.webp`).
На сайте они подключаются слоем «фоновые вставки» (`data/redesign.json → backdrops`, `src/backdrops.js`, `css/backdrops.css`, `js/backdrops.js`) — на всех страницах, в том числе на главной
(там — на блоках ниже героя; героя, вступления с баночкой, бегущей строки и блока «Астрея в цифрах» они не касаются). На странице «Компания» в начале — только крупный логотип. Молекулы редкие: «Обучение», «Партнёры» и один блок главной.
Страницы брендов и товаров получают фон по очереди из нескольких вариантов (`variants`), поэтому у соседних страниц он разный; на брендах — только упаковка, крем и шёлк, без молекул и пузырьков.

| Текстура | Как нарисована | Скрипт |
|---|---|---|
| `cream` крем | карта высот из параллельных S-образных валиков + шёлковый шейдинг на numpy (без шума) | `cream.py` |
| `smear` мазок крема | numpy: два мазка — расстояние до гладкой кривой → профиль толщины (круглое начало, бортики, тонкие бороздки вдоль движения к хвосту), шёлковый шейдинг и мягкая тень | `smear.py` |
| `silk` молочный шёлк | numpy: многократно искажённый шум — плавные складки молока/шёлка с перламутровым блеском | `silk.py` |
| `ribbon` линии и сетка | numpy: перекручивающаяся лента из сотни тончайших линий, сгущения дают объём | `ribbon.py` |
| `film` плёнки | numpy: две наложенные изогнутые прозрачные плёнки со светлыми краями (без капель) | `film.py` |
| `pipette` капля и пипетка | Blender/Cycles: стеклянная пипетка (тело вращения), висящая капля, лужа-линза | `pipette.py` |
| `molecules` молекулы | Blender/Cycles: прозрачные «атомы» со стержнями, глубина резкости | `molecules.py` |
| `bottles` флаконы для шампуня | Blender/Cycles: высокие белые флаконы без надписей — овальное сечение, крышка вровень с телом, канавка на стыке и выемка под палец; ряд и три в глубине, один лежит | `bottles.py` |
| `jars` баночки | Blender/Cycles: белые баночки разного размера с мягкими крышками и золотым кантом | `jars.py` |
| `flips` флаконы пониже | Blender/Cycles: те же флаконы, но ниже и шире, два ряда и один лежащий | `flips.py` |

Общее: `common.py` (сцена Blender: свет, камера, материалы, тела вращения), `packs.py` (упаковка: баночка и белый флакон для шампуня без дозатора — тела вращения со скруглёнными кромками и пологим куполом вместо плоского верха), `shade.py` (шейдинг карты высот, шкалы тона), `export.py` (подгонка тона, WebP).

## Как перерисовать

Нужны Blender как модуль `bpy` (python 3.11; `pip install bpy`) и `numpy`, `Pillow`. Каталог сырых картинок — любой, например `/tmp/bg`.

```bash
cd tools/bg-render
python3.11 cream.py  res=1600x1100 out=/tmp/bg/cream.png         # numpy: секунды
python3.11 smear.py  res=1600x1100 out=/tmp/bg/smear.png
python3.11 ribbon.py res=1600x1100 out=/tmp/bg/ribbon.png
python3.11 film.py   res=1600x1100 out=/tmp/bg/film.png
python3.11 silk.py   res=1600x1100 out=/tmp/bg/silk.png
python3.11 molecules.py -- res=1600x1100 samples=96  out=/tmp/bg/molecules.png    # Blender: 4–10 минут на 4 ядрах CPU
python3.11 pipette.py   -- res=1600x1100 samples=96  out=/tmp/bg/pipette.png
python3.11 bottles.py   -- res=1600x1100 samples=112 out=/tmp/bg/bottles.png
python3.11 flips.py     -- res=1600x1100 samples=112 out=/tmp/bg/flips.png
python3.11 jars.py      -- res=1600x1100 samples=112 out=/tmp/bg/jars.png
python3.11 export.py /tmp/bg                                     # → ../../assets/bg/*.webp
node ../build.js && node ../check-bg.js                          # пересобрать сайт и проверить
```

Для быстрого просмотра: `res=640x440 samples=24` (Blender ~20–30 с). Параметр `seed=…` меняет случайные детали.
Для сцен из Blender важно `bounces=48` в `render_setup` — у тонких стеклянных стержней свет долго ходит внутри (полное отражение), при 12 отскоках появляются чёрные полосы.

## Как устроен тон

Всё, что рисуется, приводится к одной шкале (`export.py → WEB`): тень (203,195,183) → середина → свет (255,254,251). Текстуры накладываются на страницу умножением
(`mix-blend-mode: multiply`): белое не меняет цвет страницы, тени и блики лишь слегка затеняют, поэтому текстура всегда в палитре сайта — и на молочном, и на холодно-жемчужном фоне.
Фон кадра (медиана яркости) ставится на отметку 0.6, отклонения от него усиливаются (`gain`): прозрачное стекло остаётся деликатным, но читается. К картинке добавляется шум ±1 уровень,
чтобы на плавных градиентах не было ступеней, кодирование — WebP q92 (десктоп) / q90 (телефон); вместе все текстуры весят около полумегабайта.
Телефонная версия — портретный кадр вокруг главной части картинки (`focus` в `export.py`).

## Как менять размещение на страницах

Всё в `data/redesign.json → backdrops` (после правки: `node tools/build.js`):

* `enabled` — выключатель всей системы; `skipPages` — страницы без вставок (сейчас нет); `skipClasses` — блоки, которые не трогаем.
* `variants` — вместо одного плана у страницы можно задать несколько: `"brand": {"variants": [план, план, план]}`; страницы с этим ключом (девять брендов, товары) получают их по очереди в порядке сборки.
* `pages[<ключ страницы>]` (`home`, `catalog`, `brands`, `brand`, `product`, `training`, `event`, `news`, `article`, `company`, `contacts`, `partners`, `search`, `privacy`, `terms`; `_default` — для остальных); `logo` — крупный логотип «Астрея» на заднем плане страницы (`{"pos": "c", "o": 7}`, `o` — сотые доли непрозрачности; сейчас на «Компании»):
  `top` — полоса в начале страницы (за заголовком), `end` — полоса в конце (над подвалом), `mid` — текстура на конкретном блоке (на главной только `mid`): `{"sel": "section.sec#calc", "n": 0, "tex": "film", "pos": "r", "o": 6}`
  (`sel` — тег, классы и `#id`; `n` — какой по счёту такой блок, `-1` — последний).
* `pos`: `tr` `tl` `br` `bl` (угол), `r` `l` (сторона), `c` (по центру), `t` `b` (на всю ширину сверху/снизу), `full`. Слева текстура зеркалится: содержимое всегда лежит у края, а у текста остаётся чистое место.
* `o` — сила 3…10 (десятые доли непрозрачности); по умолчанию 0.85–0.95, у служебных страниц (`privacy`, `terms`, `search`) слабее.

## Проверка

`node tools/check-bg.js` (после сборки; `--no-browser` — только файлы и разметка; `--strict-contrast` — контраст как ошибка): файлы на месте и лёгкие, на героя, вступление и бегущую строку главной вставок нет,
на каждом типе страниц и на компьютере, и на телефоне вставки подгружаются, нет горизонтальной прокрутки и ошибок, текстура не перехватывает клики, переход между страницами без перезагрузки тоже даёт вставки,
контраст текста, лежащего прямо на текстуре, не ниже WCAG AA — по настоящему снимку страницы без текста.
