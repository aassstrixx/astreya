# Фоновые текстуры сайта (`assets/bg/`)

Семь макро-текстур за содержимым страниц (по референсу заказчика): **крем**, **нити (линии науки)**, **капли**, **микро-рельеф кожи**, **капля / пипетка**,
**блеск и свет**, **молекулы**. Рисуются здесь, готовые WebP лежат в `assets/bg/` (десктоп `<имя>.webp` и телефон `<имя>-m.webp`).
На сайте они подключаются слоем «фоновые вставки» (`data/redesign.json → backdrops`, `src/backdrops.js`, `css/backdrops.css`, `js/backdrops.js`) —
на всех страницах, **кроме главной** (по просьбе заказчика) и вступления с баночкой.

| Текстура | Как нарисована | Скрипт |
|---|---|---|
| `cream` крем | карта высот из шёлковых мазков с гребнем + шейдинг на numpy (без шума) | `cream.py` |
| `lines` нити | Blender/Cycles: стеклянные дуги-нити, стеклянные бусины, глубина резкости | `lines.py` |
| `drops` капли | Blender/Cycles: крупная капля, лужа-линза и мелкие капли (стекло с IOR воды) | `drops.py` |
| `relief` рельеф кожи | numpy: ячейки Вороного вдоль складок полотна, перспектива, глубина резкости | `relief.py` |
| `pipette` пипетка | Blender/Cycles: стеклянная пипетка (тело вращения), висящая капля, лужа-линза | `pipette.py` |
| `glints` блики | numpy: светящиеся нити (кривые Безье, пересечения горят ярче) и узлы-звёздочки | `glints.py` |
| `molecules` молекулы | Blender/Cycles: стеклянные шары и стержни, боке на заднем плане (кадр 3:1) | `molecules.py` |

Общее: `common.py` (сцена Blender: свет, камера, материалы, тела вращения, сетка по карте высот), `shade.py` (шейдинг карты высот, шкалы тона), `export.py` (подгонка тона, WebP).

## Как перерисовать

Нужны Blender как модуль `bpy` (python 3.11; `pip install bpy`) и `numpy`, `Pillow`. Каталог сырых картинок — любой, например `/tmp/bg`.

```bash
cd tools/bg-render
python3.11 cream.py  res=1600x1100 out=/tmp/bg/cream.png         # numpy: секунды
python3.11 relief.py res=1600x1100 out=/tmp/bg/relief.png
python3.11 glints.py res=1600x1100 out=/tmp/bg/glints.png
python3.11 lines.py    -- res=1600x1100 samples=128 out=/tmp/bg/lines.png     # Blender: ~5–8 минут на 4 ядрах CPU
python3.11 drops.py    -- res=1600x1100 samples=96  out=/tmp/bg/drops.png
python3.11 pipette.py  -- res=1600x1100 samples=96  out=/tmp/bg/pipette.png
python3.11 molecules.py -- res=2400x800  samples=96  out=/tmp/bg/molecules.png
python3.11 export.py /tmp/bg                                     # → ../../assets/bg/*.webp
node ../build.js && node ../check-bg.js                          # пересобрать сайт и проверить
```

Для быстрого просмотра: `res=640x440 samples=24` (Blender ~20–30 с). Параметр `seed=…` меняет случайные детали.
Для сцен из Blender важно `bounces=48` в `render_setup` — у тонких стеклянных стержней свет долго ходит внутри (полное отражение), при 12 отскоках появляются чёрные полосы.

## Как устроен тон

Всё, что рисуется, приводится к одной шкале (`export.py → WEB`): тень (203,195,183) → середина → свет (255,254,251). Текстуры накладываются на страницу умножением
(`mix-blend-mode: multiply`): белое не меняет цвет страницы, тени и блики лишь слегка затеняют, поэтому текстура всегда в палитре сайта — и на молочном, и на холодно-жемчужном фоне.
Фон кадра (медиана яркости) ставится на отметку 0.6, отклонения от него усиливаются (`gain`): прозрачное стекло остаётся деликатным, но читается. К картинке добавляется шум ±1 уровень,
чтобы на плавных градиентах не было ступеней, кодирование — WebP q92 (десктоп) / q90 (телефон); вместе все текстуры весят около полумегабайта.
Телефонная версия — портретный кадр вокруг главной части картинки (`focus` в `export.py`).

## Как менять размещение на страницах

Всё в `data/redesign.json → backdrops` (после правки: `node tools/build.js`):

* `enabled` — выключатель всей системы; `skipPages` — страницы без вставок (сейчас `home`); `skipClasses` — блоки, которые не трогаем.
* `pages[<ключ страницы>]` (`catalog`, `brands`, `brand`, `product`, `training`, `event`, `news`, `article`, `company`, `contacts`, `partners`, `search`, `privacy`, `terms`; `_default` — для остальных):
  `top` — полоса в начале страницы (за заголовком), `end` — полоса в конце (над подвалом), `mid` — текстура на конкретном блоке: `{"sel": "section.sec#calc", "n": 0, "tex": "relief", "pos": "r", "o": 6}`
  (`sel` — тег, классы и `#id`; `n` — какой по счёту такой блок, `-1` — последний).
* `pos`: `tr` `tl` `br` `bl` (угол), `r` `l` (сторона), `c` (по центру), `t` `b` (на всю ширину сверху/снизу), `full`. Слева текстура зеркалится: содержимое всегда лежит у края, а у текста остаётся чистое место.
* `o` — сила 3…10 (десятые доли непрозрачности); по умолчанию 0.85–0.95, у служебных страниц (`privacy`, `terms`, `search`) слабее.

## Проверка

`node tools/check-bg.js` (после сборки; `--no-browser` — только файлы и разметка; `--strict-contrast` — контраст как ошибка): файлы на месте и лёгкие, на главной и во вступлении вставок нет,
на каждом типе страниц и на компьютере, и на телефоне вставки подгружаются, нет горизонтальной прокрутки и ошибок, текстура не перехватывает клики, переход между страницами без перезагрузки тоже даёт вставки,
контраст текста, лежащего прямо на текстуре, не ниже WCAG AA — по настоящему снимку страницы без текста.
