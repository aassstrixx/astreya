# Декоративные камни (tools/decor)

Обломки травертина и известняка — общий декор страниц «Астреи»: стоят в 3D-сценах (зал первого экрана главной, `tools/jar-render/hall_story.py`; первый экран «Брендов», `tools/brands-assets/scene.py`)
и лежат на фоне страниц отдельными картинками с прозрачностью (`assets/decor/rock-*.webp`, описание — `assets/decor/rocks.json`).

```bash
pip install bpy numpy pillow
python3 tools/decor/rocks.py render              # весь набор (8 камней и 3 группы) → assets/decor, ≈2 мин на картинку на 4 ядрах
python3 tools/decor/rocks.py render boulder-a    # один камень или группа
python3 tools/decor/rocks.py sheet               # контрольный лист /tmp/rocks-sheet.png
RK_SCALE=.5 RK_SPP=24 RK_OUT=/tmp/rk python3 tools/decor/rocks.py render boulder-a      # быстрый предпросмотр в другую папку
```

## Как сделан камень

`make_rock()` берёт сферу из ≈10 000 вершин, смещает её крупным и мелким шумом («картошка»), затем «срезает» плоскостями: вершины за плоскостью прижимаются к ней — получаются плоские грани скола
(у плиты — плоские верх и низ), потом один проход сглаживания: рёбра не острые, как у живого камня. Материал — травертин из `tools/showroom-assets/materials.py` (поры, слои, тёплый песочный тон)
плюс крупная неровность излома (шум + «расстояние до ребра» ячеек Вороного в рельеф). Те же `make_rock()` и `ROCKS` берёт сцена зала: камни в кадре главной — этот же набор.

Картинка для страницы: камень и мягкая тень на прозрачном фоне (тень берётся как разность прозрачностей кадра «камень + пол-ловушка тени» и кадра «только камень» и красится в тёплый коричневый тон страницы),
ортографический ракурс сверху-сбоку, свет слева.

## Куда они попадают на сайте

`data/redesign.json → decor` (`src/decor.js`, `css/decor.css`): список блоков страницы (`sel`), на которые кладётся камень, его сторона, положение, размер и поворот. Страницы: главная, каталог, бренды.
Камни лежат под содержимым блока, не перехватывают клики, не создают горизонтальной прокрутки; на телефоне — крупнее (иначе теряются). Выключить: `decor.enabled = false`.

> **Статус:** вставка камней и каменного знака в фон страниц (`src/decor.js`, `css/decor.css`, `data/redesign.json → decor`) **выключена** (`enabled: false`) по решению заказчика — фон страниц делают только прежние текстуры `backdrops`. Механизм и рендеры сохранены: `enabled: true` вернёт камни по плану; id знака — `stone-sphere`, `stone-mountain`, `stone-logo`, `stone-front`.
