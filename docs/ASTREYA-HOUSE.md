# ASTREYA HOUSE — главная как архитектурный дом

Рабочий документ большой переделки главной: центральный зал со стеклянным столиком (баночка + раскрытый журнал), семь комнат с настоящим содержимым сайта, журнал как интерфейс навигации. Здесь — аудит, карта соответствия, архитектура, визуальная система и порядок работ. По ходу работы документ обновляется (внизу — журнал состояния).

* Метка в репозитории: `restore-before-astreya-house-2026-10` (коммит `f0b7a95`, ветка `claude/oryzo-ai-style-reference-ac1alz`). Вернуть прежнее состояние целиком: `git checkout restore-before-astreya-house-2026-10 -- .` (или `git revert` коммитов «HOUSE …»).

### 1.2 Технологии и что можно использовать повторно

* Чистые статические страницы, ванильный JS (`js/*.js`, без сборщика и библиотек анимации), CSS в `css/*.css`. Единственный «движок» — собственный WebGL2 `js/jar-gl.js` + `js/jar.js` (камера по глубине).
* 3D-исходники: `tools/jar-render/hall_story.py` (зал, баночка, дорожка камеры), `tools/showroom-assets/scene.py` (+ `materials.py`: травертин, известняк, штукатурка), `tools/brands-assets/scene.py` (арочные ниши брендов). Blender 5.0.1 / Cycles / OIDN доступны в окружении.
* Готовые ресурсы: фото (`assets/photos`: команда, эксперт), рендеры брендов (`assets/brands/niche-*.webp`, `hero.webp`), слои каталога (`assets/showroom`), текстуры (`assets/bg`), шрифты Fraunces / Manrope / Playfair Display (`assets/fonts`), логотип-знак (`#logo-art`).
* Ограничения: реальная производительность на видеокарте в этом окружении не измеряется (программный GL ~100× медленнее) — проверяется логика, а не fps; внешние страницы из окружения недоступны (сетевая политика) — внешние референсы изучены по описанию в задании.

## 3. Архитектура дома

```
                    ┌───────────────┐
   ┌────────────────┤  ЗАЛ (hall)   ├───────────────┐
   │  арка слева    │ столик+журнал │  арка справа  │   три видимых прохода:
   │ 02 Бренды      │ баночка       │ 05 Учебный    │   02 Бренды · 03 Подбор · 05 Учебный центр
   └──────┬─────────┤ арка в глубине├───────┬───────┘   остальные — журнал и меню комнат
          │         │ 03 Подбор     │       │
   01 О компании    └───────────────┘   06 Партнёры
   04 Экспертиза                         07 Редакция
```

### 3.1 Структура страницы (одна страница, настоящий HTML)

1. **Заставка и зал** — `#arch-story` (прокрутка кадров) заканчивается кадром зала; поверх него живые HTML-элементы: приветствие, кнопки, журнал на столике, подсказки-проходы (кнопки-ссылки), метки комнат.
2. **Комнаты** — семь `<section class="room" id="room-…">` подряд. Каждая со своим фоном (рендер интерьера в той же палитре и свете), заголовком «Комната 0N · …», настоящим содержимым и навигацией комнаты (журнал / предыдущая / следующая / в зал).
3. **Подвал** — после комнаты 07 («путь к контактам»).

Порядок в DOM — для чтения и SEO; **посетитель не обязан идти по порядку**: любая комната открывается напрямую (оба пути ниже).

### 3.2 Два равноправных пути

* **Путь 1 — пространство.** Проходы в зале: клик (или Enter) → проход мягко подсвечивается → «вуаль света» (200–300 мс) → перемещение к комнате → арка комнаты раскрывается → видно полное содержимое; кнопка «В зал» возвращает в тот же кадр зала.
* **Путь 2 — журнал.** Клик по журналу на столике → журнал плавно приближается (читальный режим) → листание → «Открыть комнату» → журнал складывается к столику → тот же переход в комнату. Оглавление журнала открывает любую комнату без перелистывания.
* Оба пути вызывают одну функцию `House.go(id)`, один и тот же адрес `#room-…` и ту же историю браузера (кнопка «Назад» возвращает в зал). Прежние якоря (`#solutions`, `#brands-gallery`, `#training-block`, `#how-to-start`, `#start-path`, `#hb-strip`, `#home-events`) остаются рабочими и открывают соответствующую комнату.

### 3.3 URL

`index.html` — зал · `index.html#room-about | #room-brands | #room-finder | #room-expertise | #room-academy | #room-partners | #room-editorial` — комнаты · `index.html#magazine` и `#magazine/3` — журнал (развороты 0–9). Углублённые страницы (`company.html`, `brands.html`, `catalog.html`, `training.html`, `news.html`, `partners.html`, `contacts.html`) остаются настоящими страницами и доступны из комнат, шапки и подвала.

### 3.4 Режимы

| Режим | Когда | Что происходит |
|---|---|---|
| **Полный** (ПК) | JS + WebGL2, нет `prefers-reduced-motion` | заставка по прокрутке, зал, перелистывание бумаги с перспективой, раскрытие арки |
| **Упрощённый** (телефон) | `max-width: 700px` / `pointer: coarse` | кадры телефона, журнал — вертикальная «колода» разворотов со свайпом, проходы — крупная вертикальная навигация по комнатам, анимации короче |
| **Без анимации** | `prefers-reduced-motion`, «лёгкий режим», нет WebGL, нет JS | зал — статичный кадр (или обычный герой), журнал — обычный список разворотов-карточек, комнаты — обычные секции; всё содержимое и все кнопки доступны сразу |

Никакого scroll-lock: страница прокручивается всегда; единственная «закреплённая» часть — прежняя заставка (она уже ограничена высотой `--jh`), а читальный режим журнала — диалог, закрывающийся Esc / кнопкой / кликом по фону.

## 4. Визуальная система

* **Палитра:** молочный `#f5f2ec`, слоновая кость `#faf6ee`, песок `#e9dcc5` / `#efe7d6`, травертин и известняк (материалы из `materials.py`), тёмно-синий `#0b1a33` / `#101f37` — только как фирменный акцент (вывески, обложка, кнопки), золото — тонкие линии `#b08e4e` и бликами, не заливкой.
* **Свет:** тёплое диагональное солнце из окна слева-сзади, мягкий заполняющий из зала; одинаковое направление теней во всех комнатах; экспозиция и look как в зале (`AgX - Punchy`), цветокоррекция без холодного сдвига (`grade()` каталога = тот же результат, что у главной).
* **Архитектурные элементы (повторяются в каждой комнате):** арка с радиусом полукруга и узким каменным обрамлением, скруглённые проходы, встроенная ниша с мягкой LED-подсветкой, каменный скульптурный постамент, массивный, но «лёгкий» столик (стекло + камень), травертиновый пол с отражением, рельефная стена (рейки).
* **Типографика:** Fraunces / Playfair для заголовков (редакционно, спокойно), Manrope для текста и интерфейса; крупные номера комнат `01–07`; подписи верхним регистром с разрядкой.
* **Движение:** только `transform`/`opacity`/`clip-path`; кривая `--ease`; 300–700 мс; раскрытие арки (маска-арка 40 → 100 %), проявление света, мягкое перелистывание; запрещены отлёты камеры, вращение всей сцены, большие скачки масштаба, scroll-lock.
* **Компоненты:** `.room` (фон, шапка, тело, навигация), `.room-door` (арка-переход к соседней комнате), `.house-nav` (компактная навигация: в зал / журнал / комнаты 01–07), `.mag` (журнал: обложка, разворот, оглавление, элементы управления), `.hall-door` (проходы-хотспоты), `.veil` (вуаль перехода).

## 5. Журнал

* **Состояния:** закрыт (обложка ASTREYA на столике), раскрыт на столике (разворот-анонс в перспективе), читальный режим (крупно, диалог), в комнате доступ через «Журнал» в навигации комнаты.
* **Разделы (развороты):** 0 обложка · 1 содержание · 2 О компании · 3 Бренды · 4 Подбор · 5 Экспертиза · 6 Учебный центр · 7 Партнёрам · 8 Редакция · 9 контакты (задняя сторона). Все тексты, цифры, фото, названия брендов — из данных сайта; номера страниц настоящие.
* **Управление:** клик по правому/левому краю страницы, свайп, ←/→ и Home/End, кнопки «Назад»/«Далее», оглавление (переход без листания), «Обложка», «Закрыть» (Esc), «Открыть комнату» (ссылка `#room-…`).
* **Технология:** HTML/CSS (3D-трансформации только на десктопе, одна страница — один элемент `transform: rotateY`), без WebGL и без библиотек; на телефоне — горизонтальный `scroll-snap` с тем же содержимым; при `prefers-reduced-motion` — мгновенная смена разворота.
* **Доступность:** журнал — `role="dialog"` с `aria-modal`, фокус внутри, возврат фокуса на столик, `aria-live` для номера страницы; все ссылки — настоящие `<a>`.

## 6. Производительность и проверка

* Бюджет: HTML ≤ 200 КБ, добавочный CSS/JS ≤ 60 КБ (до сжатия), фоны комнат — WebP ≤ 180 КБ каждый (ленивая подгрузка по подходу к комнате), кадры зала — те же 60 ключевых кадров (≈ как сейчас, 23 МБ на диске, на странице грузятся по блокам), журнал без картинок-«скриншотов» (только настоящие фото сайта и CSS).
* Проверки (как «основные сценарии»): все существующие `tools/check-*.js` (в режиме `house.enabled=false` — как раньше), новый `tools/check-house.js` (зал → комнаты обоими путями, журнал: клик/свайп/клавиатура/оглавление/закрытие/возврат, адреса и «Назад», ссылки и якоря Stella, reduced-motion, телефон, без JS, ошибки картинок), замер веса и времени до первого кадра, ручные скриншоты ПК/телефон.
