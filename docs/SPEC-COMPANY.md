# ТЗ: «ASTREYA Grand Atrium» (company.html) — требования заказчика

Источник — MASTER PROMPT заказчика «ASTREYA COMPANY» (пересказ по пунктам; дословный текст в журнале сессии не сохранился). Общие правила проекта — `docs/PAGES-V2-BRIEF.md`. Совет заказчика (принят): не 5–6 независимых 3D-сцен, а **один качественный центральный рендер архитектуры + веб-сцены поверх**.

## Blender
Проект `ASTREYA_COMPANY_ATRIUM.blend` (`tools/showroom-assets/atrium/`), экспорт `company_atrium.glb` (если разумно по размеру), рендеры WebP для ПК / телефона / деталей, необязательная камера-анимация 5–7 с (или параллакс слоёв глубины, как в сценах главной/каталога). Материалы: ASTREYA_TRAVERTINE, ASTREYA_IVORY_STONE, ASTREYA_SAND_STONE, ASTREYA_NAVY_METAL, ASTREYA_BRUSHED_CHAMPAGNE, ASTREYA_ARCH_GLASS. Камеры: main, wide, sculpture, arch, side. Cycles CPU + OIDN, не более 2 потоков, цвет под общий цвет сайта (`regrade_site.py`).

## Девять сцен страницы
1. **Вход:** «О КОМПАНИИ» / «Астрея — пространство профессиональной косметологии» / кнопка «Познакомиться с компанией».
2. **Четыре направления** в четырёх каменных нишах.
3. **Выставка брендов:** Dermatime, Keenwell, Cantabria Labs (линии Endocare / Neoretin / Heliocare / Biretix / Iraltone / Elancyl — отдельно от производителя), EVA — отдельно; реальные проектные изображения; кнопки «Все бренды» и «Перейти в каталог».
4. **Шесть панелей доверия** — без стандартных иконок.
5. **Комната профессионалов** — с обязательной оговоркой, что подбор ориентировочный.
6. **Учебный центр** — два реальных ближайших события из данных и кнопка «Посмотреть расписание».
7. **География:** Москва (штаб-квартира: проезд Березовой рощи, д. 8, 3-й этаж, Пн–Пт 10:00–18:00, +7 (495) 925-51-62), Санкт-Петербург (191186, Большая Конюшенная ул., д. 27, БЦ «Медведь», офис 406) — офисы; Ростов-на-Дону и Симферополь — города семинаров (не офисы); Онлайн. Карточки по наведению, «Все контакты». Адреса строго из `data/site.json`.
8. **Пространство партнёрства:** «Стать партнёром» + калькулятор.
9. **Финал «Познакомимся на практике»:** две панели — «Учебный центр» и «Старт со Стеллой».
