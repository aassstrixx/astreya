# Раздел «Статьи» (библиотека Astreya)

Страницы: `articles.html` (библиотека) и `articles/<slug>.html` (по странице на статью). Страница собирается статически, как остальные (`tools/build.js`), поэтому прямая ссылка и обновление страницы работают на GitHub Pages; несуществующий адрес показывает `404.html` (он закрыт от индексации).

## Данные — `data/articles.json`
Единая структура для будущего подключения к админке (как `data/news.json`):

* `categories` — рубрики `{id, name}` (Пилинги, Уход за кожей, Активные ингредиенты, Возрастные изменения, Профессиональная косметология, Экспертные рекомендации);
* `items` — статьи: `slug` (латиница, цифры, дефисы — адрес страницы), `title`, `date`, `excerpt` (анонс и описание для поисковиков), `intro` (вводный абзац), `categories` (несколько рубрик; первая — основная и показывается на карточке), `brand` (необязательно: статья попадает в блок «Полезные статьи» на странице бренда), `cover` `{src, alt, pos, caption}`, `blocks`, необязательно `seoTitle`, `seoDescription`, `related` (slug статей для «Читайте также»).
* Блоки статьи (`blocks`): `p`, `h2` (попадает в оглавление), `h3`, `ul`, `ol`, `quote` (`text`, `by`), `info` / `warn` (`title`, `text`), `table` (`caption`, `head`, `rows`, `note`), `img` (`src`, `alt`, `caption`, `pos`). В тексте допустимо `**жирное**`.
* Время чтения считается при сборке по тексту (около 180 слов в минуту, не меньше 3 минут). Сборка останавливается с понятным сообщением, если нет slug, повторяется slug, нет рубрики или бренда.
* Тексты самих страниц (заголовок раздела, «Все материалы», «Читайте также», примечание «Материал носит образовательный характер…») — реестр «Тексты страниц» (`src/texts/articles.js`, страницы «Библиотека статей» и «Страница статьи»); SEO-шаблоны — `src/texts/seo.js`.
* Изображения — из банка сайта (`assets/photos`, `assets/news`); подписи и описания лежат в данных статьи.

## Разметка и поведение
* `src/pages/articles.js` — `libraryPage`, `materialPage`; подключение — `tools/build.js` и `data/redesign.json → pageAssets` (`library`, `material`).
* `css/pg-articles.css`, `js/pg-articles.js`. Библиотека: фильтр по рубрикам (число карточек в кнопке, адрес `?cat=…`, без JS видны все материалы), раскладка карточек зависит от числа видимых (крупная 8×2, малые, половины, во всю ширину) — функция `sizes()` одинакова в шаблоне и в скрипте. Статья: кнопка «← Все материалы», рубрика, дата, время чтения, обложка, колонка 720 px, оглавление по `h2` (на компьютере прилипает, на телефоне свёрнуто и сворачивается перед прокруткой), подсветка текущего раздела, полоса прогресса чтения (`transform: scaleX`), таблицы на телефоне — карточками с подписями столбцов, «Читайте также».
* Анимации — только `transform` и `opacity`; `html.lite`, `prefers-reduced-motion` и устройства без наведения отключают их. Анимация появления карточек при фильтрации — `animation-fill-mode: backwards` (иначе она навсегда фиксирует `transform` и убивает подъём при наведении).

## Где статьи подключены
* «Обучение» → «Полезные статьи»: три строки-ссылки, кнопка «Читать все статьи» ведёт в библиотеку (раскрытие списка убрано).
* Страницы брендов → «Статьи бренда»; «Читайте также» внутри статей; новости → блок «Экспертные материалы» под газетой; поиск (`js/data.js`, тип «страница») и `sitemap.xml`.
* Карточка статьи (`src/components.js → articleCard(a, P)`) — ссылка с обложкой статьи; адрес обложки в `--cv` пишется от папки `css/` (`../assets/…`).
* Старый список статей `data/training.json → articles` удалён: `ctx.training.articles` — те же статьи из `data/articles.json`.
