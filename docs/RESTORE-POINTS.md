Как вернуться:

```
git fetch origin restore/2026-11-11-before-creative-redesign
git switch -c rollback-2026-11-11 origin/restore/2026-11-11-before-creative-redesign   # новая ветка с прежней версией
# или посмотреть без переключения:  git diff origin/restore/2026-11-11-before-creative-redesign..HEAD --stat
```

Теги git-прокси среды не принимает (push тега обрывается), поэтому точка возврата — защищённая от случайных правок отдельная ветка; её не двигаем, а новые точки возврата создаём под новыми именами. Историю рабочей ветки не переписываем.
