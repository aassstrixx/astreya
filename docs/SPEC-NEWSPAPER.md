# ТЗ: интерактивная газета «Астрея» (news.html) — требования заказчика

Источник — MASTER PROMPT заказчика «ASTREYA INTERACTIVE NEWSPAPER» (пересказ по пунктам; дословный текст в журнале сессии не сохранился). Общие правила проекта — `docs/PAGES-V2-BRIEF.md`.

## Замысел
`news.html` — интерактивная премиальная газета на каменном столе (реалистичная бумага, тени, свет, текстуры, гамма сайта). Ожидаемый результат заказчика (референс из трёх кадров): 1) первое состояние — газета-бумага лежит на столе; 2) раскрытый номер с разворотами; 3) взаимодействие (перелистывание, подсказки).

## Обязательное
1. **Сцена и вход.** Каменный стол, газета на нём. Камера наклонена над столом и от прокрутки опускается к газете; это НЕ блокирует прокрутку страницы. Кнопка «Открыть газету» (пропуск вступления).
2. **Листание — настоящая физика.** CSS-3D (perspective, preserve-3d, без новых библиотек): пружинный поворот листа, изгиб бумаги, динамические тени на нижнем листе и на столе, блик, «отлип» уголка при наведении/перетаскивании, свайп, кнопки, клавиатура, индикатор страниц.
3. **Разворот и содержание.** Обложка; акции; новинки; экспертное; обучение и события; компания и регионы + подписка. Все 9 реальных статей из `data/news.json` с реальными текстами, датами, категориями и ссылками сохраняются. Промо «Скидки по объёму закупки» с «ДО 15%» (число из данных) и ссылками на `partners.html#calc` и «Стать партнёром».
4. **Фильтры и навигация.** Рабочие фильтры Все / Новости / Акции / Новинки / Обучение / Мероприятия + панель оглавления + deep links (адрес открывает нужный разворот/статью).
5. **Статья.** Открывается поверх газеты (оверлей) с возвратом на тот же разворот; отдельные страницы статей (`articlePage`) тоже в новом оформлении (бумага/типографика/камень), CTA-логика прежняя.
6. **Стелла.** Контекстные подсказки через существующий помощник (`asst-open`/`asst-chip`), не второй чат, без изменений бэкенда.
7. **Подписка.** Рабочая форма через существующую форму/обработчик (`S.formHTML('subscribe', …)`), ничего нового на бэкенде.
8. **Мобильная версия.** Одна страница на экран, свайп.
9. **Запасные режимы.** Без WebGL/без JS — читаемый статичный список статей (прежний fallback сохранить); `prefers-reduced-motion` уважать (смена разворота кроссфейдом, без физики; кнопку «Без анимации» не добавлять).
10. **Изоляция.** Весь CSS под корневым классом (`.np`); шапку, подвал и другие страницы не менять.
11. **Фото.** Подобрать и согласовать по цвету с сайтом (`tools/showroom-assets/regrade_site.py`). Назначения: n7/n8 → семинарные фото `assets/academy/video-2`/`video-3`; n2/n6 → `video-3`/`video-4`; n1 (акция) — типографическое «ДО 15%»; n3/n5 → спрайты упаковок `eva-device`/Dermatime; n4 → Heliocare/Neoretin; n9 → `assets/photos/photo-02-about` (команда).
12. **Особый контроль качества (слова заказчика):** физика перелистывания и переход от первого экрана к раскрытой газете — проверять покадрово (несколько углов поворота листа, несколько фаз входа).
13. «Не объявляй функции готовыми, если они не работают.» Отзывы/опросы не выдумывать.
