Папка: `tools/showroom-assets/textures/<slug>/` — `color.jpg`, `normal.jpg` (OpenGL), `rough.jpg`, `ao.jpg`, `disp.jpg`, `preview.jpg` (512 px), у металлов ещё `metal.jpg`. Все файлы скачаны с Poly Haven и ambientCG; лицензия CC0 1.0 (проверена: Poly Haven — на странице ассета и на polyhaven.com/license, ambientCG — на страницах сайта; в API ambientCG отдельного поля лицензии нет). Ничего не сгенерировано. Файлы перепакованы в JPG q86 (PIL), содержимое карт не менялось. Одно уточнение: `rough.jpg`, `ao.jpg`, `disp.jpg` сохранены в градациях серого, `ao.jpg` и `disp.jpg` — не больше 1K.

## Подключение в Blender (bpy)

```python
import bpy, os
ROOT = "tools/showroom-assets/textures"

def pbr_material(slug, name=None, scale=1.0, metal=False):
    d = os.path.join(bpy.path.abspath("//"), ROOT, slug)
    mat = bpy.data.materials.new(name or slug); mat.use_nodes = True
    nt = mat.node_tree; nt.nodes.clear()
    out = nt.nodes.new("ShaderNodeOutputMaterial")
    bsdf = nt.nodes.new("ShaderNodeBsdfPrincipled")
    nt.links.new(bsdf.outputs["BSDF"], out.inputs["Surface"])
    uv = nt.nodes.new("ShaderNodeTexCoord")
    mp = nt.nodes.new("ShaderNodeMapping"); mp.inputs["Scale"].default_value = (scale,)*3
    nt.links.new(uv.outputs["UV"], mp.inputs["Vector"])

    def tex(fn, colorspace):
        p = os.path.join(d, fn)
        if not os.path.exists(p): return None
        n = nt.nodes.new("ShaderNodeTexImage"); n.image = bpy.data.images.load(p)
        n.image.colorspace_settings.name = colorspace
        nt.links.new(mp.outputs["Vector"], n.inputs["Vector"]); return n

    c = tex("color.jpg", "sRGB")
    if c: nt.links.new(c.outputs["Color"], bsdf.inputs["Base Color"])
    r = tex("rough.jpg", "Non-Color")
    if r: nt.links.new(r.outputs["Color"], bsdf.inputs["Roughness"])
    n = tex("normal.jpg", "Non-Color")            # OpenGL-нормали: Blender ждёт именно их
    if n:
        nm = nt.nodes.new("ShaderNodeNormalMap")
        nt.links.new(n.outputs["Color"], nm.inputs["Color"])
        nt.links.new(nm.outputs["Normal"], bsdf.inputs["Normal"])
    if metal:
        mt = tex("metal.jpg", "Non-Color")
        if mt: nt.links.new(mt.outputs["Color"], bsdf.inputs["Metallic"])
    return mat

travertine = pbr_material("travertine-ivory", scale=2.0)
brass = pbr_material("brass-brushed-pale", metal=True)
```

Заметки:
- `color` — sRGB; `normal`, `rough`, `ao`, `disp`, `metal` — **Non-Color**.
- AO по желанию: Mix (Multiply) между `color` и Base Color. Displacement — нода Displacement (Scale ≈ 0.01–0.03) и Cycles Adaptive Subdivision, если нужен реальный рельеф.
- Перекраска (например, красный бархат → тёмно-синий): Hue/Saturation/Value между `color` и Base Color, `color.jpg` на диске не трогаем.

## Что не нашлось (честно)

- **Рифлёная (fluted) панель** — настоящих fluted-панелей (полукруглые рейки) в CC0 на этих двух источниках не нашлось. Взяты ближайшие: `ribbed-concrete-boards` (ambientCG Concrete045, вертикальный опалубочный бетон) и `ribbed-concrete-dark` (Poly Haven ribbed_concrete_wall). Для настоящих flutes лучше геометрия плюс травертин или дуб в Blender.
- **Тёмно-синий бархат** — не нашёлся. Есть красный `velvet-velour-red` (Poly Haven velour_velvet); синий делается Hue/Saturation нодой. Синие `knit-wool-blue`, `linen-blue-ph` и `terry-towel-blue` — не бархат.
- **Букле** — точного нет. Ближайшие: `boucle-cream-teddy` (Poly Haven curly_teddy_natural, кремовый тедди-флис) и `knit-wool-white` (трикотаж). Poly Haven wool_boucle — клетчатая шерсть, не подошла.
- **Латунь/шампань** — в ambientCG нет слов «brass», «champagne»; взяты бледно-золотые металлы Metal048B (браш) и Metal042A (матовое золото). Цвет получается жёлтым — при необходимости слегка охладить в Blender.
- **Лён, кремовый** — отдельного «linen» нет; `linen-cream-weave` — кремовая тканая ткань Fabric032 (рогожка), `linen-blue-ph` — синий лён с Poly Haven.
- **Кожа кремовая (необязательно)** — не взята: в ambientCG только тёмные/коричневые/оранжевые (Leather039 слишком оранжевый), в Poly Haven leather_white зелёно-серая.
- **Нет AO** у большинства ассетов ambientCG, которые не предоставляют эту карту (в `maps` манифеста видно). Для них AO не подставлялся.
- Превью-хосты (`cdn.polyhaven.com`, `acg-media.struffelproductions.com`) недоступны из этой среды, поэтому выбор делался по скачанным 1K-текстурам.

## Правила

1. **Только CC0.** Poly Haven — всё CC0. ambientCG — CC0. Любые другие источники (CC-BY, «free for personal use», маркетплейсы) не добавляем.
2. Перед добавлением открыть страницу ассета и убедиться в лицензии; ссылку и ID записать в `manifest.json`.
3. Формат: `tools/showroom-assets/textures/<slug>/color.jpg|normal.jpg|rough.jpg|ao.jpg|disp.jpg|preview.jpg`, JPG q≈86, 2K для «героев», 1K для остальных; `ao`/`disp` — 1K. Нормали только OpenGL (`NormalGL` / `nor_gl`).
4. Общий вес библиотеки — не больше 70 МБ (`du -sh tools/showroom-assets/textures`).
5. Не подставлять сгенерированные или процедурные картинки под видом скачанных. Если файл не скачался, пишем об этом здесь.
6. Slug — латиница в нижнем регистре через дефис; в `manifest.json` обязательны `slug`, `title`, `source_url`, `asset_id`, `license`, `resolution`, `physical_size_m`, `maps`, `astreya_usage`.
