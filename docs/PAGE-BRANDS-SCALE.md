# «Бренды»: уменьшение масштаба (версия 3, 16.11.2026)
Просьба владельца: «Я НЕ ХОЧУ, ЧТОБЫ ВЕСЬ РАЗДЕЛ БРЕНДОВ СОСТОЯЛ ИЗ ТАКИХ МАСШТАБНЫХ КОНСТРУКЦИЙ» — сохранить арки, стекло, кремовые тона, латунь и продукцию, но уменьшить пропорции, сделать текст заметнее и характеристики бренда — в компактной карточке. Рендеры не менялись.

## brands.html
- Витрина-стена (assets/brands/wall.webp) теперь рамка по центру `min(100% − 2·gut, 1180px)`: высота ≤ 535 px вместо ≈ 650 px стены на весь экран (вместе с заголовком блок был ≈ 850 px, стал ≈ 735 px). Всё внутри (ниши, логотипы, упаковки, заголовок, фильтры) масштабируется целиком, потому что размеры заданы в долях кадра и `cqw` контейнера `.bw-stage`.
- Заголовок получил мягкое свечение (text-shadow) поверх стены; правила — конец css/brands-wall.css («Версия 3»).
- Панель бренда при нажатии на нишу, поиск, фильтр по задачам, нижняя полоса «Портфель брендов» — без изменений.
## Страница бренда
- Компоновка (≥ 901 px): слева компактная арочная витрина (≈ 46% ширины, высота `clamp(380px, 35vw, 520px)`), справа информационная карточка: страна/группа, название, описание, направления (теги), число позиций/линеек/семинаров, действия («Смотреть ассортимент», «Стать партнёром»). Ниже — «Путь с брендом», «О бренде» с паспортом, линейки (арки меньше), ассортимент, задачи, мероприятия, материалы, CTA.
- Телефон: путь → витрина (≈ 300–400 px) → карточка → остальное; линейки по две в ряд.
- Стили — src/detail/brand.css (все под `.dtb`), собираются `node tools/build-detail.js`; разметка — src/pages/brand-page.js (описание и направления перенесены в карточку).
