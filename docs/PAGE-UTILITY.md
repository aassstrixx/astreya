# Служебные страницы v2 — «Старт со Стеллой», поиск, юридические страницы, 404

Единый материал: камень/травертин, арочные ниши, мягкий свет из окна, латунь точечно, тёмно-синие кнопки — гамма сайта (hue 83–89°). Всё оформление — в `css/pg-*.css`, поведение — в `js/pg-*.js`, подключаются через `data/redesign.json → pageAssets` (файл не правился). Бизнес-логика, тексты документов, данные и параметры адреса прежние.

## Замысел по страницам

- **Старт со Стеллой** (`start.html`, `src/pages/start.js`, `css/pg-start.css`, `js/pg-start.js`; планировщик рисует прежний `js/sales.js` в `#plan-app`). «Консьерж-салон»: рендер зала (круглая стойка, арочные ниши с упаковками) на первом экране; поверх справа «лист бумаги» с диалогом Стеллы; ниже «папка-досье» с итогом: линейки, товары, семинары билетами с датой, условия закупки, справочные факты, действия (форма менеджеру, добавить в список запроса, скопировать ссылку на план, спросить Стеллу, печать). На телефоне заголовок короткий, диалог начинается сразу и по высоте подстроен под видимую область (`visualViewport`, учитывает экранную клавиатуру). Логика подбора, дат и расчёта не менялась.
- **Поиск** (`search.html`, генератор `src/pages/misc.js`, результаты строит прежний `js/pages.js`, логика индекса — `js/core.js`; `css/pg-search.css`, `js/pg-search.js`). «Картотека»: стена с девятью нишами, строка запроса на каменной плите (≥ 52 px), быстрые подсказки; результаты группами («ящики»: товары, бренды, обучение, новости) с миниатюрой (упаковка товара, логотип бренда, дата семинара, значок новости), вкладки-фильтры, подсветка найденного; пустой результат предлагает популярные запросы и разделы. Русское написание бренда («Дерматайм») ведёт к латинскому названию в индексе — это только подсказка поиску (таблица `ALIAS` в `js/pg-search.js`), на страницах ничего нового не утверждается. Параметр `?q=` и `data-track="search_result_click"` сохранены; клавиша `/` фокусирует строку.
- **Юридические страницы** (`privacy`, `terms`, `consent`; `css/pg-legal.css`, `js/pg-legal.js`, разметка — `legalPage` в `src/pages/misc.js`). Документная вёрстка: слева оглавление-навигатор (собирается из заголовков документа, текущий раздел подсвечивается по прокрутке, `aria-current="location"`) и навигация между тремя документами; справа «лист» с текстом (строка ≤ 72 знаков, золотые маркеры, таблицы). **Тексты не менялись** — скрипт только добавляет заголовкам якоря. До заполнения реквизитов оператора (`data/site.json → requisites`) вместо документа показывается прежняя заглушка, оглавление скрыто.
- **404** (`css/pg-404.css`, `js/pg-404.js`). «Потерялись в галерее»: пустой зал с тремя арками, «404» вырезано в камне, растерянная жемчужина Стеллы с вопросом (следит за указателем, веселеет при вводе запроса), строка поиска, четыре «таблички» — каталог, бренды, обучение, поиск. Пути в 404 абсолютные (страницу отдаёт GitHub Pages на любой глубине).

## Материалы и ассеты

Готовые WebP в `assets/utility/`: `salon(-wide)(-m)` (старт), `wall(-s)` (поиск и полоса юридических страниц; на этих страницах картинка отзеркалена CSS, чтобы дерево не лежало под текстом), `arches(-m)` (404). Рендер — Blender 5.0.1, Cycles CPU + OIDN, скрипт `tools/showroom-assets/utility/salon.py`, цвет подогнан `tools/showroom-assets/regrade_site.py`. Пересборка: `blender -b -P tools/showroom-assets/utility/salon.py -- --threads 2`, затем подгонка цвета (`regrade_site.py --stats` до и после) и сохранение в WebP ≤ 500 КБ. Остальное — CSS-материалы (бумага, плита, латунный кант, мягкие тени); анимируются только `transform`/`opacity`, `prefers-reduced-motion` уважается.

## Проверки

- `node tools/check-utility.js` (новая, порт 0): старт — все шаги до итога и действия итога (на 1440 и 390), поиск («Дерматайм», «крем», «семинар», пустой запрос, отправка формы), юридические страницы (оглавление, якоря, подсветка, совпадение текста с исходной разметкой), 404 (ссылки, поиск), нет ошибок консоли и горизонтальной прокрутки. Для юридических страниц собирается временная копия сайта с тестовыми реквизитами в `/tmp/astreya-site-util-*` (удаляется после прогона).
- Затронутые прежние: `check-sales.js` (строки про фильтр городов и лист ожидания обновлены под страницу «Обучение»: `#city-chips .chip[data-id]`, `#sem-list .sem-item`, `[data-sx-wait]`), `check-stella.js`, `check-assistant.js`, `check-extras.js`.
- Проверено только в Chromium без GPU (Playwright) и в Blender. Не проверено на реальном GPU, в Safari и на iPhone.

- **Взгляд Стеллы на «Старте» (17.11, просьба владельца, вторая версия):** лицо целиком (глаза, щёки, рот) мягко поворачивается к курсору — до ±3,6 ед. вьюбокса по горизонтали и ±2,8 по вертикали (≈ ±19 px на орбе 250 px), амплитуда растёт с расстоянием (предел ≈ 200 px). Глаза на лице неподвижны (первая версия двигала глаза отдельно от рта и щёк — они «разъезжались»). Положение зависит только от движения курсора: при прокрутке страницы не пересчитывается (раньше сбивалось); курсор покинул окно — Стелла смотрит прямо; на тач-экранах не меняется; «думает/спит» — штатные состояния. Измерено: смещение глаз относительно рта 0 px, лицо относительно корпуса ±19 px, после прокрутки на 500 px положение не изменилось. Код: `js/pg-start.js` (`look`), `css/pg-start.css`.
