# Страница «Компания» — «ASTREYA Grand Atrium» (v2)

Требования заказчика — `docs/SPEC-COMPANY.md`, общие правила — `docs/PAGES-V2-BRIEF.md`. Совет заказчика принят: **один центральный рендер атриума + девять веб-сцен поверх него**, а не девять отдельных рендеров.

## Замысел
Страница — проход по светлому атриуму из травертина: арки, ниши, латунь цвета шампань, тёмно-синий металл, арочное стекло. Первый экран — сам рендер (камера `main`), при прокрутке он «шагает вглубь» (масштаб и сдвиг слоя через `--hp`), в лучах света летят 24 пылинки (canvas). Дальше сцены сменяют друг друга; три последних кадра атриума (`side`, `arch`, `wide`) работают фонами сцен 5, 8 и 9 с мягким параллаксом. Остальные сцены собраны из готовых проектных материалов сайта (ниши брендов, спрайты упаковок, travertine-текстура) и CSS: арки-ниши, каменные панели, латунная ось географии.

## Файлы
- `src/pages/company.js` — разметка девяти сцен (данные только из `data/*.json` через `ctx`).
- `css/company-atrium.css` — все стили под корнем `.ca`.
- `js/company-atrium.js` — поведение (подключается через `data/redesign.json → pageAssets → company`): шапка, навигатор по сценам, параллакс, пылинки, наклон панелей, города, калькулятор. Очистка при уходе со страницы.
- `assets/company/` — `atrium.webp` (2400), `atrium-s.webp` (1200), `atrium-m.webp` (1080×1620, телефон), `atrium-side.webp`, `atrium-arch.webp`, `atrium-wide.webp` (детальные кадры).
- `tools/showroom-assets/atrium/` — `atrium.py` (сцена), `ASTREYA_COMPANY_ATRIUM.blend`, `render_all.sh` (резюмируемый рендер всех кадров), `finish.py` (доводка в WebP).
- `tools/check-company.js` — проверка в браузере (66 пунктов).
- Правка чужой проверки: `tools/check-sales.js`, строка про «завершающий призыв компании» — искалась старая полоса `.cta-band h2`, теперь `.cta-band h2, .ca-final h2` (смысл тот же: «Познакомимся на практике»).

## Blender (`tools/showroom-assets/atrium/`)
Сцена: атриум 23 × 38 м — колоннада с каннелюрами и аркадой, клеристорий со световыми нишами, балочный потолок со световыми щелями, полированный травертиновый пол с латунной осью и синими вставками, на глубине — арочный портал со стеклянным экраном и тёмно-синими стойками, в центре — скульптура по мотивам знака (два каменных клинка, латунное кольцо-«орбита», шар из слоновой кости на двухступенчатом основании; знак не копируется, настоящий логотип остаётся веб-слоем).
- Материалы: `ASTREYA_TRAVERTINE`, `ASTREYA_IVORY_STONE`, `ASTREYA_SAND_STONE`, `ASTREYA_NAVY_METAL`, `ASTREYA_BRUSHED_CHAMPAGNE`, `ASTREYA_ARCH_GLASS` (камень — CC0-пак `tools/showroom-assets/textures`).
- Камеры: `cam_main`, `cam_wide`, `cam_sculpture`, `cam_arch`, `cam_side`, `cam_mobile`, `cam_dolly` (пролёт 5–7 с: широкий план → скульптура; анимация сохранена в `.blend`, 150 кадров при 24 к/с; в страницу не подключена).
- Cycles CPU + OIDN, строго 2 потока (`AT_THREADS`, по умолчанию 2).

Как пересобрать:
```
cd tools/showroom-assets/atrium
python3 atrium.py preview                      # быстрый кадр /tmp/at_preview.png (AT_CAM=wide|sculpture|arch|side|mobile)
./render_all.sh                                # итоговые кадры в /tmp/at_raw (резюмируемо: готовые пропускаются); в фоне: setsid nohup ./render_all.sh > /tmp/atrium.log 2>&1 &
python3 finish.py main && python3 finish.py mobile && python3 finish.py wide && python3 finish.py arch && python3 finish.py side
python3 atrium.py save                         # пересохранить .blend (и .glb, если нужен)
```
Цвет: `finish.py` вызывает `tools/showroom-assets/regrade_site.py` (сначала `--stats`, затем подгонка к a 0,8 / b 10,5). Замеры до и после — в разделе «Проверено».
`company_atrium.glb` (≈ 3,9 МБ) **не** положен в репозиторий: больше порога ≈ 3 МБ, странице не нужен.

## Библиотеки
Новых нет и внешних запросов нет (CSP строгий): CSS, IntersectionObserver, canvas 2D, requestAnimationFrame. WebGL не используется — запасной вариант «нет WebGL» не требуется. Blender 5.0.1 (`bpy`), OIDN; для доводки — Pillow, numpy, OpenCV (как в остальных рецептах `tools/showroom-assets`).

## Поведение и запасные варианты
- Без JS: все девять сцен статичны, карточки городов раскрыты, калькулятор показывает пороги (ползунок без скрипта не считает — расчёт делает `js/company-atrium.js`).
- `prefers-reduced-motion`: нет «шага вглубь», пылинок, мерцания лучей, наклона панелей и параллакса; переходы почти мгновенные. Кнопки «Без анимации» нет.
- Анимируются только `transform` и `opacity`; слои обновляются в `requestAnimationFrame` и только у видимых сцен; пылинки на паузе вне экрана.
- Телефон: вертикальный кадр `atrium-m.webp`, ниши в одну колонку, города — аккордеон, кнопки на всю ширину, цели касания ≥ 44 px.

## Чего не хватает / замечания координатору
- Реальный GPU, Safari и iPhone не проверялись; рендер оценён только по снимкам Chromium (swiftshader).
- В `data/site.json` Ростов-на-Дону и Симферополь значатся «Представительство», а по ТЗ — города семинаров (не офисы); страница следует ТЗ (без адресов и телефонов этих городов, «Все контакты» ведёт на `contacts.html`), данные не менялись. Старые тексты («Москва, Санкт-Петербург, Ростов-на-Дону и Крым — представительства рядом с партнёрами») сохранены как есть — стоит согласовать формулировку.
- Продающий слой (`js/sales-pages.js`) добавляет под «Мы рядом» блоки «Ваш регион» и «Почему «Астрея» можно доверять» (4 из 6 тех же преимуществ): с сценой 4 они частично дублируются. Убрать можно в `data/sales.json → pages.company.trust` (файл не менялся).
- Ближайшие события выбираются при сборке (как на главной); без пересборки список не обновляется.
- Кадр `cam_sculpture` в проекте есть, но готовый рендер на страницу не поставлен (кадр не использован).
- Пролёт камеры (`cam_dolly`) сохранён в `.blend`, видео не рендерилось: вместо него — параллакс слоёв.
